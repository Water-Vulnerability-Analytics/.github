# Water Vulnerability Analytics (WaVA)

**Open-source tools for transparent, reproducible water resource vulnerability assessment.**

Water managers face a common challenge: understanding which water resources are most exposed to change, which are most sensitive, and where limited monitoring and investment should be prioritized.

**Water Vulnerability Analytics (WaVA)** is an open-source ecosystem of analytical tools, data infrastructure, and decision-support applications designed to make those assessments reproducible, adaptable, and transparent. Rather than rebuilding methods for each project, WaVA turns vulnerability analytics into reusable community infrastructure.

## What lives here

WaVA repositories include:

- Vulnerability assessment methods and analytical packages
- Spatial and hydroclimate data workflows
- Water supply and water rights data infrastructure
- Interactive decision-support applications such as RAPID
- Utilities for retrieving, harmonizing, and analyzing environmental data

The ecosystem currently centers on **water supply vulnerability** but is designed to support additional water-resource applications over time.

## Why open source?

Water vulnerability does not have one universally correct formula. Dataset choices, metrics, thresholds, and weighting schemes depend on local conditions and management needs.

WaVA provides a shared foundation that is **transparent, reproducible, tested, and adaptable**, while allowing users to modify methods for their own context.

## Contributing

We welcome contributions ranging from small fixes to new analytics, including:

- Reporting issues or regional data problems
- Improving documentation and tests
- Adding datasets, connectors, or export formats
- Reviewing or extending existing methods
- Contributing new vulnerability analytics
- Adapting decision-support tools to new locations

WaVA grew from collaborative work at **Colorado State University** with the **National Park Service** and other partners, but is being developed as a community-oriented home for water vulnerability tools across institutions and sectors.
